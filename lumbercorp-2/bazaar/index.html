Enter your Torn API key

Torn requires a valid API key on every API request, so this scanner needs yours to pull bazaar data.

How to get a key:
  1. On torn.com, click your username (top-right) → Settings
  2. In the API key section, generate a key with access level Full (at least Limited — bazaar data is blocked for lower levels)
  3. Copy the 16-character key and paste it below

Your key is stored only in this browser (localStorage) and is sent only to api.torn.com via this server — it is never logged or shared. You can remove it anytime with “change key” → clear.
